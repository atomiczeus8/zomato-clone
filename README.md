## Project Architecture: Zomato 2.0 Clone

This project leverages modern frontend techniques to deliver a highly optimized, fluid, and interactive user experience without relying on heavy external libraries or frameworks.

### Core Concepts Implemented

* **Fluid Responsive Layout:** Utilizes CSS `clamp()` functions and viewport units (`vw`, `vh`) to ensure the design mathematically scales up and down perfectly across any screen size, acting like a fluid digital poster.
* **Scroll-Driven Animation Engine:** Implements the native `IntersectionObserver` API to monitor elements entering the viewport. This efficiently triggers staggered CSS transitions (reveals, fades, and pops) without bogging down the main thread.
* **Dynamic Statistical Counters:** Uses a custom `requestAnimationFrame` loop combined with a cubic easing function to smoothly animate the numbers in the stats section when scrolled into view.
* **Accessibility (a11y) Guard:** Integrates CSS media queries (`@media (prefers-reduced-motion: reduce)`) and JavaScript `window.matchMedia` checks to automatically halt parallax and complex animations for users who prefer reduced motion.
* **🤖 AI-Assisted Development:** To accelerate the workflow, optimize performance, and write cleaner code, AI tools were utilized to help construct the complex CSS stylings and refine the JavaScript logic throughout the build.
